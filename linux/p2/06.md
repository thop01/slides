# 1. Minder typen

Tab-aanvulling en je eigen aliassen

---

<!-- _class: demo -->

## Tab, Tab… en verder typen

- **Eén keer Tab:** vult aan als er één passende mogelijkheid is.
- **Twee keer Tab:** toont in Bash meestal de mogelijkheden.
- Typ meer letters en druk opnieuw op **Tab**.
- Aanvulling werkt voor commando’s en bestands- of mappaden.

**Probeer:** typ `cat /etc/prot` en druk op **Tab**.
Druk pas op Enter als je het volledige commando wilt uitvoeren.

> Tab vult aan; Enter voert uit. De mogelijkheden hangen af van je shell en de ingestelde aanvulling.

---

## Een alias: je eigen korte commando

Een **alias** geeft een bestaande opdracht een korte naam.

```bash
alias overzicht='ls -1'
overzicht
```

- `alias` maakt de snelkoppeling.
- `overzicht` is de naam die je zelf kiest.
- De tekst tussen aanhalingstekens is de opdracht.

**Let op:** geen spaties rond het `=`-teken.

---

<!-- _class: demo -->

## Aliassen bekijken en verwijderen

```bash
alias
alias overzicht
unalias overzicht
```

1. `alias` toont je ingestelde aliassen.
2. `alias overzicht` toont de definitie van één alias.
3. `unalias overzicht` verwijdert die alias uit deze shell.

Een alias die je in de terminal maakt, verdwijnt als je die shell sluit.

---

## Je alias bewaren voor een volgende keer

Open je Bash-instellingen:

```bash
nano ~/.bashrc
```

Voeg onderaan één keer deze regel toe:

```bash
alias overzicht='ls -lah'
```

Bewaar met **Ctrl + O**, **Enter** en sluit met **Ctrl + X**.
Laad de wijziging met `source ~/.bashrc` en test `overzicht`.

<!-- In Ubuntu laadt een nieuwe interactieve Bash-terminal ~/.bashrc. Laat bestaande instellingen staan. Nano wordt later in deze les uitgebreider behandeld. -->

# 2. Tekst maken en lezen

Van een korte notitie tot een groot logbestand

---

## Een nieuw bestand maken met echo

```bash
cd ~/les6
echo "dit is een nieuw bestand" > nieuw.txt
cat nieuw.txt
```

- `echo` schrijft de tekst naar de standaarduitvoer.
- `>` stuurt die uitvoer naar `nieuw.txt`.
- `cat` leest het bestand en toont de inhoud in je terminal.

> Bestaat `nieuw.txt` al? Met `>` overschrijf je de inhoud.

---

<!-- _class: demo -->

## Een regel toevoegen: gebruik >>

```bash
echo "dit is de tweede regel" >> nieuw.txt
cat nieuw.txt
```

Je ziet nu:

```text
dit is een nieuw bestand
dit is de tweede regel
```

**Voorspel:** wat zou er gebeuren als je `>` gebruikt in plaats van `>>`?

---

## Een groot tekstbestand rustig bekijken

```bash
cat /etc/protocols | less
```

`cat` leest het bestand. De pipe `|` geeft de uitvoer door aan `less`.

- **Spatie:** een scherm verder; **b:** een scherm terug.
- **Pijltjes:** een regel omhoog of omlaag.
- **`/tcp` + Enter:** zoek naar `tcp`; **n:** volgende treffer.
- **q:** sluit `less` en keer terug naar de prompt.

Zonder pipe kan het ook: `less /etc/protocols`.

---

## Alleen het begin of einde bekijken

```bash
ls /etc | head -20
cat /etc/protocols | tail -n 10
```

- `head -20` toont de eerste 20 regels van de invoer.
- `head -n 20` is de duidelijkere schrijfwijze van hetzelfde.
- `tail -n 10` toont de laatste 10 regels.

**Vraag:** welk commando kies je voor de laatste gebeurtenissen in een logbestand?

---

<!-- _class: demo -->

## Een logbestand live volgen

```bash
tail -f /var/log/auth.log
```

`tail -f` toont de laatste 10 regels en blijft nieuwe regels volgen.
Stop het volgen met **Ctrl + C**.

- **Permission denied?** Gebruik `sudo tail -f /var/log/auth.log`.
- **Bestand ontbreekt?** Sommige Ubuntu-systemen gebruiken alleen het journal. Bekijk dat live met `sudo journalctl -f`.

<!-- Het journal bevat meer dan alleen authenticatieberichten. Er verschijnt pas nieuwe uitvoer wanneer er nieuwe gebeurtenissen zijn. -->

# 3. Commando’s combineren

De uitvoer van de één is de invoer van de ander

---

## Piping: stap voor stap

```bash
ls /etc | head -20 | nl
```

1. `ls /etc` toont de namen in `/etc`.
2. `head -20` neemt de eerste 20 regels over.
3. `nl` voegt regelnummers toe aan niet-lege regels.

**Gegevensstroom:** `ls` → `head` → `nl` → terminal.

Een pipe `|` stuurt uitvoer naar een volgend programma.
Met `>` stuur je uitvoer naar een bestand.

<!-- ls gebruikt bij uitvoer naar een pipe standaard één naam per regel. Dit is een oefening in het bekijken van uitvoer, geen algemene methode om bestandsnamen in scripts te verwerken. -->

---

5. Controleer het bestand met `cat`.

# 4. Tekst bewerken met nano

Openen, aanpassen, zoeken en opslaan

---

<!-- _class: demo -->

## Je eerste bewerking in nano

```bash
cd ~/les6
nano nieuw.txt
```

1. Verplaats de cursor met de pijltjestoetsen en voeg tekst toe.
2. Druk op **Ctrl + O** om op te slaan.
3. Bevestig de bestandsnaam met **Enter**.
4. Sluit met **Ctrl + X** en controleer met `cat nieuw.txt`.

Onderin betekent `^` **Ctrl**: `^O` is dus **Ctrl + O**.

---

<!-- _class: table -->

## Nano: hulp en bestanden

| Sneltoets | Functie   | Wat doet het?                              |
| --------- | --------- | ------------------------------------------ |
| Ctrl + G  | Help      | Opent de ingebouwde handleiding.           |
| Ctrl + O  | Write Out | Slaat op; bevestig de naam met Enter.      |
| Ctrl + X  | Exit      | Sluit; vraagt zo nodig of je wilt opslaan. |
| Ctrl + R  | Read File | Voegt een ander bestand in bij de cursor.  |

**Probeer:** open Help en ga met **Ctrl + X** terug naar je tekst.

---

<!-- _class: table -->

## Nano: zoeken en navigeren

| Sneltoets | Functie    | Wat doet het?                            |
| --------- | ---------- | ---------------------------------------- |
| Ctrl + W  | Where Is   | Zoekt een woord of tekst.                |
| Ctrl + \  | Replace    | Zoekt tekst en vervangt die.             |
| Ctrl + C  | Location   | Toont het huidige regel- en kolomnummer. |
| Ctrl + /  | Go To Line | Springt naar een opgegeven regelnummer.  |

**Probeer:** zoek `bestand` en spring daarna naar regel 1.

<!-- Ctrl+/ wordt niet in elke terminal hetzelfde doorgegeven. Gebruik zo nodig Alt+G. Toetsen kunnen verschillen per versie of configuratie; raadpleeg Ctrl+G en de onderbalk. -->

<!-- _class: table -->

## Nano: tekst bewerken

| Sneltoets | Functie | Wat doet het?                                |
| --------- | ------- | -------------------------------------------- |
| Ctrl + K  | Cut     | Knipt de huidige regel of gemarkeerde tekst. |
| Ctrl + U  | Paste   | Plakt tekst uit nano’s knipbuffer.           |
| Ctrl + J  | Justify | Breekt regels in een alinea opnieuw af.      |
| Ctrl + T  | Execute | Opent opdrachten en extra functies.          |

De beschikbare extra functies hangen af van de context.
Bekijk bij afwijkende toetsen **Ctrl + G** of de onderbalk.
